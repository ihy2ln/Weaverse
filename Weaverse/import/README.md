# Drop Novelcrafter ZIPs here

Put a **full export** ZIP in this folder (`novel.md` **or** `novel.docx` plus `characters/`, `locations/`, `lore/`, …).

On first desktop start with an empty library, Weaverse imports the first ZIP it finds.

You can also click **Import** on the web hub (`http://127.0.0.1:8787/`).

On Android: top-bar **Import** / **Export** (novels, roleplay, notes). App backup stays in Settings.

`isekai-gacha-full-word.zip` is included as the sample Word export.
