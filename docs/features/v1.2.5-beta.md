## What the product is

Offline-first novel writing (Novelcrafter-style) plus SillyTavern-style
roleplay, on **Android**, **Windows desktop**, and a **web hub** served by
the desktop companion. No account, no cloud. Sync is peer-to-peer over Wi-Fi
or a tunnel you control, gated by a one-time password from the hub.

Modules: `app` (Android / Compose / Room / Hilt), `sync-core` (JVM shared
sync + Novelcrafter ZIP), `desktop` (Ktor hub + Go launcher). Package
`com.ihy2ln.weaverse`. `minSdk` 26, `compileSdk` 35, `targetSdk` 34, JDK 17.

## Workspaces (Android)

Five top-level modes in `AppMode` / the chrome:

| Mode | Destinations (`*Destination`) |
|---|---|
| **Novel** | Bookshelf · Plan · Write · **Read** · Chat · Review |
| **RPG** (`Roleplay`) | Campaign · Inventory · Adventure · Town · Roster · Lore · Presets |
| **Chatting** | Chats · Contacts |
| **Storyboard** | Window · Manga · Comic |
| **Notes** | Board |

Chrome also has Extra tools (Codex, Prompts, Notes, Snippets, Chats,
Pictures) and a Focus switch between writing canvas and picture gallery.

Home is the book-button hub: a card per mode, novels underneath.

### Novel

- **Bookshelf** — library of novels in this workspace.
- **Plan** — outline: Book → Act → Chapter → Scene → Scene beat. Write jump
  can open a Scene, Scene beat, or Chapter.
- **Write** — block editor for the scene document (`docJson`). Paragraphs,
  media blocks, stacks, scene beats, slash `/` and backslash `\` prompts,
  find/replace, undo, scene revisions. Pictures are copied into
  `filesDir/media/{uuid}.{ext}` and referenced by `mediaId`. See
  [`novel-write-read.md`](novel-write-read.md).
- **Read** — premium reader: Paper / Sepia / Night, font size, line spacing,
  contents sheet, bookmarks, volume-key / swipe paging, read-aloud TTS,
  progress bars. **At this checkpoint it is text-only** (renders
  `plainText`, not media blocks).
- **Chat** — workshop threads about the book (not roleplay).
- **Review** — read-through pass over the manuscript.

Shared: Codex (with lorebook fields), Snippets, prompt library.

### RPG

Campaign uses the same manuscript shape as a novel (Adventure ≈ Book, Day ≈
Chapter, Mission ≈ Scene). Roster is You / Team; Inventory is You → Team →
Roster equipment plates. Lore is adventure-scoped. Presets inject difficulty
into the system prompt (Slice of life / Normal / Hard / Ruthless). **Town**
is a walkable side-scrolling map with enterable buildings (`f63ebaf`).

### Chatting / Storyboard / Notes

- Chatting: Contacts from the character codex; Chats with All / Unread /
  Groups.
- Storyboard: comic pages; Manga is right-to-left, Comic left-to-right;
  panels hold media.
- Notes: global board (`SnippetEntity` with `category = "notes"`).

Roleplay chats still have three display modes: Messenger, DM 3×3, manga 6×6,
with hold → Move, stack-on-drop, and audio.

## Data the reader and writer share

Scene persistence is one Room row (`SceneEntity`):

- `docJson` — kotlinx.serialization `Document` (`classDiscriminator = "type"`).
  Blocks include `Paragraph`, `Heading`, `Quote`, `ListItem`, `Divider`,
  `MediaBlock`, `MediaStackBlock`, `MediaGridBlock`, `SceneBeatBlock`,
  `CodeBlock`.
- `plainText` — denormalized text for search / word count / AI. **Media
  blocks contribute nothing** to this string.
- `wordCount`, `beatsJson`, POV, labels, etc.

`MediaEntity` is the app-wide media table (`relativePath` under private
storage, mime, dimensions). Write's `MediaRepository.importFromUri` already
copies picker bytes into that folder before inserting a block.

The reader at this tag loads `getReaderScenes(bookId)` once (JOIN
acts→chapters→scenes), then keeps `ReaderScene.text = plainText`. Switching
to Read after adding a picture in Write therefore cannot show the picture:
the block structure was discarded, and the query is not observed live.

## AI, sync, import/export

- Providers: OpenRouter (model browse), plus OpenAI / Anthropic / Gemini
  profiles. Keys in EncryptedSharedPreferences, not in the Room DB that
  syncs.
- Global `/` (AI) and `\` (manual) prompt overlay; prompt library with a
  real templating engine on later `main` work — **this tag already has the
  multi-message / workshop path used by Write**.
- Sync: desktop Ktor hub, one password on the web page, Android Settings →
  Open web sync, Push / Pull / auto-sync. Record-level merge so a pull does
  not wipe unsaved work. See `Weaverse/SYNC.md`.
- Import: Novelcrafter ZIP, SillyTavern, PNG character cards.
- Export: project zip, EPUB (`EpubWriter`), backups (hourly snapshots +
  daily).
