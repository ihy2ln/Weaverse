# Review

Review lives under **Write ▾** (not Plan):

- **Review scene** — current scene plain text + Codex context  
- **Review chapter** — all scenes in the chapter  

## What you get
- Editorial notes (continuity, voice, pacing, Codex consistency)
- Context meter for the packed prompt
- Usage log (tokens / cost when the provider returns them)

## Model
Uses the remembered **Review** action model, else Settings default.
