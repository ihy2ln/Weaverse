# Backup, Sync, and Troubleshooting

## Backup and import/export

Export important works and project extras to ZIP/JSON and verify the files
outside app-private storage. NovelCrafter archives with `novel.docx` or
`novel.md` and character folders are supported. Imported Codex folders map to
Characters, Locations, Objects, and Lore.

## Peer-to-peer sync

1. Start the desktop package and open its local web hub.
2. Copy the displayed one-time password.
3. Open **Settings → Open web sync** on Android and enter it.
4. Use Auto-sync or manual Push/Pull.

Sync is peer-to-peer over your Wi-Fi or tunnel; there is no required Weaverse
cloud account.

## Common fixes

- **Only one Codex category:** tap its category name for the popup; drag the
  divider down for the expanded list.
- **Prompt missing:** open Write or a play surface, then expand PROMPT if it is
  condensed.
- **AI silent:** check API key, network, model, and /A mode.
- **Media absent:** verify the asset source and Pictures, then restore from a
  known-good export if needed.
- **Too many cards/chats:** hold an item, select it for quick remove, add more
  selections, and confirm Quick remove.
- **APK will not update:** a signing or application-ID mismatch may be present.
  Export first; uninstall only the conflicting package, then reinstall.

Source recovery details are in the repository's
`docs/CHECKPOINT-v1.3.2-CODEX-NAVIGATION.md` file.
