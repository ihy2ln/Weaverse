# AI & Prompting

## Shortcuts
- `/` — AI prompt dock  
- `\` — Manual insert  

## Preview
Toggle preview to see assembled system text before generate.

## Per-action models
Each action can remember its own OpenRouter model ref:
- Scene beat · Shorten · Extend · Replace · Summarize  
- Review · Roleplay swipe · Workshop · Prompt AI  

Blank = follow Settings default.

## Context meter
Shows approximate token use by section (Codex · Scene · User).  
When the budget is tight, overflow Codex entries are dropped from the **actual** prompt, not only from the chip list.

## Scene beat Models
While a scene beat overlay is active, a bottom strip exposes Models + context meter (the full AI overlay is hidden for beats because the card lives in the document).
