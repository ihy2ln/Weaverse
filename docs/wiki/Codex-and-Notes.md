# Codex and Notes

Codex and Notes are shared across every book and mode, but serve different
purposes. Use Codex for named, structured reference material. Use Notes for
research, lists, and free-form ideas.

## Codex list

Open **Extra → Codex**. Before an entry is selected, category sections use the
mode screen. Expand/collapse headings and use a category's **+** to add an entry.

## Codex entry navigation

Opening an entry changes the layout:

- The shared entry count appears in the title band.
- A one-line, horizontally scrollable strip sits under the title.
- The strip contains the active category and its entries.
- Tap the category word to open a popup of all categories and counts.
- Pick Characters, Locations, Lore, Objects, or a custom category to jump there.
- Tap an entry name to switch entries; the current entry stays highlighted.
- Tap **+** to create an entry in the selected category.

Drag the divider under the strip downward to see more entries or upward to
condense it. The single chevron in the entry toolbar collapses or restores the
rail and replaces the older back/forward pair.

Entry fields include name, aliases/nicknames, reference text, and media. Names
and aliases create tappable mentions where Codex-aware writing views support
them.

## Notes

The shared Notes board uses the workspace until a note is opened. Select a note
to edit it; use the microphone for speech-to-text. Notes does not show the
generation prompt dock because it is a direct editing tool.
