# Prompts and AI

The prompt dock is available on actual writing and play surfaces, not on Home,
Bookshelf, Campaign, Window, reading, Notes, Codex, or management screens.

The expanded dock has prompt text above one compact control row:

- **W min–max** requests a generation word range.
- **Model** opens the OpenRouter model list; a long model name scrolls.
- **/A · \\M** toggles AI generation or manual entry.
- **✓** accepts the current result.
- **×** clears or cancels it.
- The microphone starts speech input.

The small **PROMPT** control at the upper-left collapses the dock. Collapsed, it
occupies only a label and triangle at the bottom of the workspace.

If generation fails, verify the OpenRouter key, model selection, connection,
and /A mode. The maximum word value is a strong instruction to the model, not a
perfectly enforceable tokenizer boundary.
