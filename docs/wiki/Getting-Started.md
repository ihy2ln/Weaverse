# Getting Started

1. Tap the book icon for Home.
2. Choose Novel, RPG, Chatting, Storyboard, or Notes.
3. Select a work from Bookshelf, Campaign, or Window, or create one.
4. Use the second menu to move between that mode's workspaces.
5. Open Extra for shared Codex, Prompts, Notes, Snippets, Chats, and Pictures.

Weaverse saves while you edit. The top Import and Export actions make portable
backups. Keep a recent export outside the app before installing a test build.

The full prompt dock intentionally appears only on Write and play surfaces. A
shelf, reader, Codex entry, Notes board, or management screen does not need it.

## Offline and AI

Books, campaigns, chats, storyboards, notes, local media, import, export, and
organization are offline-first. AI generation needs internet access, an
OpenRouter API key in Settings, and a selected text model.

## Test builds

A test APK uses `com.ihy2ln.weaverse.debug`, so it can often install beside the
normal app. Signing differences can still require uninstalling a conflicting
build. Export first: uninstalling or clearing storage can remove local data.
