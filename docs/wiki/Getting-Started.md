# Getting Started

## Before you write
1. Install the APK from [Releases](https://github.com/ihy2ln/Weaverse/releases).
2. Open **Settings** → paste your OpenRouter API key.
3. Optionally pick a default model.

## First scene
1. **Library** → create or open a book.
2. **Novel → Write**.
3. Type a paragraph. Long-press to Format.
4. Add a Codex character, then type their name in the scene — tap the link to peek.

## First AI beat
1. Write ▾ → **Scene beat**, or insert a beat card.
2. Describe what should happen → Generate.
3. Accept into the manuscript, or Retry.
4. Use **Models** on the beat strip to pin a preferred model for scene beats.

## First review
1. Write ▾ → **Review scene** (or chapter).
2. Run review; skim continuity notes.
3. Check the Context meter so you know what Codex was packed.
